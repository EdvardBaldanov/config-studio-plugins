# Config Studio Official Plugins Registry 🧩

Official extension registry and catalog feed for [Config Studio](https://github.com/EdvardBaldanov/config-studio).

Hosted automatically via **GitHub Pages**:
- **Registry Endpoint**: [`https://edvardbaldanov.github.io/config-studio-plugins/registry.json`](https://edvardbaldanov.github.io/config-studio-plugins/registry.json)
- **Showcase Portal**: [`https://edvardbaldanov.github.io/config-studio-plugins/`](https://edvardbaldanov.github.io/config-studio-plugins/)

## 🚀 How it works
Config Studio synchronizes this catalog directly from GitHub Pages in real-time. When a new plugin or language pack is published, users can install it in **1 click** without needing to recompile the main Config Studio binary!

## 📦 How to submit a Plugin to the Registry
1. Ensure your plugin follows the [Plugin Specification](https://github.com/EdvardBaldanov/config-studio-plugin-docs).
2. Fork this repository.
3. Add your plugin entry to `registry.json`.
4. Create a Pull Request. Once merged, your plugin instantly appears for all Config Studio users!
